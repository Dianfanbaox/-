# 数据与AI配置

## 本地数据

正式入口使用IndexedDB数据库pwos-ui-v3，示例入口使用pwos-ui-v3-preview。浏览器与Android、不同浏览器和URL来源分别保存本地数据。卸载应用或清除浏览器数据可能丢失记录，请自行保存JSON备份。

云同步尚待对接；设置页面出现配置入口不代表已启用可靠的云端同步。

## 盘点与结算

收入和支出用于计算本月存钱，资产总额来自账户的实际盘点余额。填写收入后仍需确认资产余额，系统据此检查差异，不自动把每笔收入累加到账户余额。

## AI

在设置中选择MiniMax或OpenAI兼容自定义接口，填写地址、模型与自己的API Key，并测试连接。不要将Key、真实备份或配置截图提交到仓库或Issue。

Android请求经原生网络桥发送到配置的服务；网页使用浏览器fetch。AI识别、分析或问答会向该服务发送相应输入或财务汇总，请根据自己的数据偏好决定是否启用。普通记录、结算计算和本地查看无需依赖AI。模型平台的计费、权限和配额由所选服务决定。

AI提供辅助解释与识别，财务数值仍由确定性规则计算；月度分析不可用时使用内置规则并提示原因。
